# NOVA Goods

A responsive, front-end e-commerce storefront with 60 products, category browsing, live search, saved items, quick-view product details, and a client-side cart.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Vercel detects Next.js automatically; deploy with the defaults.

The project has no environment variables or database dependency. The cart and saved list are designed as an interactive front-end prototype; connect the checkout button to Stripe, Shopify, or your preferred commerce backend when ready.
